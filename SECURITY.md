# Security and confidential data

These tools are intended for local processing. Please do not report security issues or share raw Agilent data in a public GitHub issue. Report suspected vulnerabilities privately through GitHub's private vulnerability reporting for this repository, or contact the repository maintainer through the organization's approved channel.

When sharing a bug, remove patient/customer identifiers, batch numbers, personal paths, credentials, and proprietary chromatograms. A synthetic or metadata-only reproducer is preferred.
